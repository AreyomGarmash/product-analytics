# PA-S1 — анализ портфеля автомобильного страхования

Индивидуальный проект (трек Б), дисциплина «Продуктовая аналитика».  
**Автор:** Грмаш Артём Александрович  
**Группа:** ИУ6-71Б  
**Репозиторий:** https://github.com/AreyomGarmash/product-analytics  
В ноутбуке: постановка задачи, аудит реальных данных, метрики, план трекинга, когортное удержание активных договоров и финансовые показатели.

## Запуск

1. Установить Python 3.11+.
2. В папке проекта выполнить: `python -m pip install -r requirements.txt`.
3. Запустить `jupyter notebook PA_S1_Motor_Insurance.ipynb` и выбрать **Run All**.
4. Проверить, что сжатый CSV лежит в `data/Dataset of motor insurance portfolio.csv.gz`. Распаковывать его не нужно: pandas прочитает файл напрямую. Пути в ноутбуке относительные.

## Источник данных и атрибуция

*A detailed dataset of motor insurance policies with coverage-specific financial information*, авторы Priscila Espinosa, Josep Lledó, David Atance; версия 1 (2026), Mendeley Data, DOI 10.17632/sw4jmdb2sm.1: https://data.mendeley.com/datasets/sw4jmdb2sm/1. Лицензия, указанная источником, — CC BY 4.0. Файлы из скачанного набора:

- `data/Dataset of motor insurance portfolio.csv.gz`
- `data/Descriptive of variables.xlsx`

Исходный CSV весит около **94,7 МБ**. Для удобства публикации он включён в репозиторий в формате **gzip (около 25,7 МБ)**. Содержимое строк не менялось. GitHub ограничивает загрузку через веб-интерфейс отдельными файлами размером 25 МиБ; сжатый файл меньше этого лимита. Если сайт не примет файл, загрузите его через Git в командной строке или Git LFS. Данные взяты из официальной публикации и распространяются с указанием авторства.

## Ключевые расчёты

- 354 140 строк (договор × год), 185 678 уникальных ID полисов.
- Retention **активных полисов** 2022→2023: 80,06%; 2023→2024: 81,15%.
- Loss Ratio за период: 70,29%.
- CAC / LTV-CAC нельзя определить без бюджета привлечения; это ограничение требует согласования.
- Нет пользовательских событий с датами по дням: используется только годовая аналитика.

## Публикация в GitHub

В новый репозиторий загрузите **содержимое этой папки**, а не ZIP-файл. В веб-интерфейсе GitHub файлы с точкой в начале (например, `.gitignore`) могут быть скрыты в диалоге выбора — проверьте их наличие после загрузки.
